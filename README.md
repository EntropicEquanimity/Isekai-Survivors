# Isekai Conquerors

A survivors-like horde strategy game in Unity 6 on the BlondieUtils packages. Jack, isekai'd as a demon, invades a Planet Region by Region with hordes of demons while the mortals defend.

- Design and plan: `docs/plans/isekai-conquerors.md`
- Words the project uses: `CONTEXT.md`
- Game code: `Assets/Game` (`Rules` is engine-free, `Unity` holds the MonoBehaviours, `Tests` has Pure and Play Mode tests)
- Dev tools: `Assets/Dev/Editor`

The legacy survivors game lives on the `main` branch.
