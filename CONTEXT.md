# Isekai Survivors

Jack is pulled from Earth onto alien planets. He inhabits a Vessel for each Run, fights through a timed expedition, and Extracts what he can back to his Soul World — a Hades-style room that grows as he walks a Skill Tree.

## Language

### People

**Jack**:
The persistent person pulled from Earth. He inhabits a Vessel for each Run and returns to the Soul World after Extraction.
_Avoid_: the player (when you mean the person in the fiction), protagonist as a roster slot

**Vessel**:
A playable body Jack inhabits for a Run — Knight, Samurai, Rogue, and later bodies. Different starting weapons, stats, and Affinities; same Soul, same Extraction. The first Run always uses Rogue; other Vessels unlock on the Skill Tree or by clearing Planets. Rogue's Affinities are Crit, Shadow, Blade, and Dodge.
_Avoid_: character (when you mean the loadout), class, hero, skin, champion

**Soul**:
Jack's unique persistent being. It is what lets him return from a Planet, what the Skill Tree upgrades, and what manifests as the Soul World. During a Run it shapes XP into Weapons and Items.
_Avoid_: spirit, save file, meta profile

### The loop

**Run**:
An expedition onto a Planet. Jack lands, fights a timed sequence of Phases, and attempts to Extract through a scheduled Extract Window. The first Run is a cold open: Jack is already on the Planet, with no Soul World and 0% Salvage, and wakes in the Soul World only after that Run ends.
_Avoid_: session, match, game, attempt

**Phase**:
A timed slice of a Run with one Wave Type and an enemy mix. Phases are scripted per Planet, not chosen by a live director.
_Avoid_: minute mark, stage (when you mean a slice of a Run), wave (when you mean the whole Phase)

**Extract Window**:
The scheduled return period at the end of a Run — an Extract Wave Type. If Jack is alive when it ends, he is pulled back — a Successful Run. A visible portal during the window is an optional early Extraction, not a missable fail.
_Avoid_: drop pod, portal phase, end timer (as the event itself)

**Extraction**:
The return from a Planet to the Soul World with Materials collected during the Run. Weapons and Items shaped from XP dissolve; they do not Extract. A Successful Run Extracts all Materials; a Failed Run Extracts only Salvage.
_Avoid_: cash-out, end of match

**Successful Run**:
A Run that ends without Jack dying through the Extract Window. All collected Materials Extract.
_Avoid_: win, clear, victory

**Failed Run**:
A Run that ends in death. Salvage Extracts; the rest of the Materials are lost. Shaped Weapons and Items still dissolve.
_Avoid_: game over, wipe (as the whole outcome)

**Salvage**:
The portion of collected Materials that Extract on a Failed Run. Starts at 0%. The Skill Tree can raise it to a cap of 50%.
_Avoid_: death tax, keep rate, loot recovery

**Secondary Objective**:
An optional task during a Run. Completing it grants Materials and a Boon. Ignoring or failing it has no other consequence; the only way to lose a Run is to die. The starting types are Vein, Mark, Rescue, Ward, and Shrine. More types can be added later.
_Avoid_: side quest, mission, bounty, mandatory objective

**Vein**:
A Secondary Objective: mine a node in place while enemies keep coming. Pays Materials-heavy.
_Avoid_: mining, ore node

**Mark**:
A Secondary Objective: kill a marked Hoarder or Elite. Pays a Signature Material.
_Avoid_: bounty, hunt, kill target

**Rescue**:
A Secondary Objective: stand a zone on a downed local for a duration. No escort. Pays Materials and a small Boon.
_Avoid_: escort, save the locals

**Ward**:
A Secondary Objective: keep an object alive for a duration. The object dying withholds the reward; the Run continues. Pays a strong Boon and some Materials.
_Avoid_: defend, protect, escort (the object)

**Shrine**:
A Secondary Objective: activate, fight a short burst, and roll a reward — Godsplinter or a random Boon.
_Avoid_: altar, pray, gamble (as the type name)

**Boon**:
A short in-run gift from a Secondary Objective — extra XP, a weapon level, a shield, and the like. It never Extracts.
_Avoid_: powerup, buff (as the reward object), blessing, room reward

### Combat

**Wave Type**:
How a Phase brings enemies. The types are Horde, Flight, Squad, Mix, and Extract.
_Avoid_: spawn table, encounter (as this idea)

**Horde**:
A Wave Type: a spike in count, cheap Chasers, surround.
_Avoid_: swarm, rush

**Flight**:
A Wave Type: Flyers from off-screen. Giant Bat is the prototype.
_Avoid_: air wave, bat wave

**Squad**:
A Wave Type: a small clump of tougher units that spawn together and stay together.
_Avoid_: pack, patrol, elite wave (as this type)

**Mix**:
A Wave Type: weighted random spawns around Jack. Default filler.
_Avoid_: normal wave, standard spawn

**Extract**:
The Wave Type of the Extract Window: denser mixed pressure, portal visible.
_Avoid_: final wave, boss wave (as this type)

**Role**:
What an enemy is for in a fight. An enemy has one Role and may also be Elite. The Roles are Chaser, Exploder, Elite, Flyer, Ranged, Buffer, Summoner, and Hoarder.
_Avoid_: enemy type (when you mean this job), archetype, class

**Chaser**:
A Role: walks at Jack, contact damage. Most of a Horde.
_Avoid_: melee, grunt, zombie

**Exploder**:
A Role: bursts on death or when it closes.
_Avoid_: bomber, kamikaze, suicide enemy

**Elite**:
A Role (and a flag on other Roles): fat, telegraphed, extra XP.
_Avoid_: champion, mini-boss, rare

**Flyer**:
A Role: airborne, ignores ground clutter. Flight waves bias toward this Role.
_Avoid_: bat, flying enemy

**Ranged**:
A Role: keeps distance and shoots.
_Avoid_: spitter, archer (as the Role)

**Buffer**:
A Role: hangs back and auras allies. The aura is visible.
_Avoid_: support, shaman, healer (unless it actually heals)

**Summoner**:
A Role: spawns extras from itself. Those extras hit a global cap so the screen cannot melt.
_Avoid_: spawner, breeder, necromancer (as the Role)

**Hoarder**:
A Role: the loot-drop enemy. Tanky or fleeing. Extra Materials on kill. Marks often point at these.
_Avoid_: loot bug, treasure enemy, carrier

### Places

**Planet**:
A destination for a Run. Different Planets have different Signature Materials, Phases, and Secondary Objectives. Planet select is locked until after the first return to the Soul World.
_Avoid_: level, stage, map, biome (when you mean the destination of a Run)

**Soul World**:
The Soul made visible: a Hades-style room Jack returns to between Runs. The room is the menu — there are no hub NPCs. Unlocking Skill Tree sections enlarges the room. Buildings and Decorations unlock inside it.
_Avoid_: hub, base, hideout, meta menu, town, soul room

### Meta progression

**Skill Tree**:
The persistent upgrade path through the Soul. It spends Materials. Unlocking new sections also increases the size of the Soul World. Combat power, Salvage, Vessel unlocks, and room-size sections all live here.
_Avoid_: talent tree, prestige, mirror, unlocks (as the whole system)

**Building**:
A functional object in the Soul World. The starting set is the Heart (Skill Tree), Wardrobe (Vessel), Orrery (Planet), and Reliquary (Materials and Salvage).
_Avoid_: facility, station, NPC (when you mean the structure)

**Heart**:
The Building that opens the Skill Tree.
_Avoid_: mirror, altar (when you mean this Building)

**Wardrobe**:
The Building that selects the Vessel for the next Run.
_Avoid_: character select, closet, armory

**Orrery**:
The Building that selects the Planet for the next Run.
_Avoid_: map table, planet select, gate

**Reliquary**:
The Building that shows held Materials and current Salvage.
_Avoid_: inventory, stash, vault

**Decoration**:
A cosmetic unlock that can be placed in the Soul World. Cheaper than Buildings; leftover Material spend.
_Avoid_: furniture (as the whole system), ornament

### Currencies and Offers

**XP**:
In-run substance of Jack's Soul. Collecting it lets the Soul shape Weapons and Items at level-up. It never Extracts.
_Avoid_: essence, soul energy, exp as a meta currency, experience (as a mundane RPG stat)

**Offer**:
A Weapon or Item presented at level-up, shaped from XP. Chance to appear is weighted by how many Affinities it shares with the current Vessel — more shared Affinity, higher chance. Not a hard class lock.
_Avoid_: level-up choice, loot drop, card, item pool

**Affinity**:
A label on Vessels, Weapons, and Items. It weights Offers; it does not wall them. Rogue has Crit, Shadow, Blade, and Dodge.
_Avoid_: tag, keyword, class, trait, type

**Weapon**:
An in-run attack shaped from XP. It dissolves at Extraction. A Vessel starts the Run holding one.
_Avoid_: gun, spell (as the whole idea)

**Item**:
An in-run modifier shaped from XP — equipment, passives, and the like. It dissolves at Extraction.
_Avoid_: equipment (as the whole idea), relic, accessory

### Currencies (meta)

**Material**:
A rare, named substance found on Planets — not mundane ore. It is the only meta currency. It Extracts (subject to Salvage) and is spent on the Skill Tree, Buildings, and Decorations.
_Avoid_: resource, loot, ore, gold, essence, soul energy (as a currency)

**Echolith**:
The Material that drops on every Planet. Spent on generic Skill Tree stats.
_Avoid_: common ore, dust, darkness

**Signature Material**:
A Material unique to a Planet (one or two per Planet) that gates that Planet's Skill Tree branch, Buildings, and Decorations. The first Planet's Signature Material is Riftamber.
_Avoid_: rare ore, planet loot
