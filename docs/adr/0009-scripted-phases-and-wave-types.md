# Runs are scripted Phases with named Wave Types

The current game is one timed spawn table. We decided a Run is a playlist of Phases (~12 minutes on the first Planet, then a 60–90s Extract Window). Each Phase has a Wave Type — Horde, Flight, Squad, Mix, or Extract — and an enemy mix. Scripted, not a live director. First Planet: two Secondary Objectives; later Planets: three. Combat does not pause for story.
