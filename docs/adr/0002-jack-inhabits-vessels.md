# Jack inhabits Vessels

The story is Jack-only; the existing game already has Knight, Samurai, and Rogue select, and we want more playable bodies. We decided Jack is the persistent person and those bodies are Vessels he inhabits for a Run — same Soul, same Extraction, different starting weapons and stats. That keeps the roster and the isekai identity instead of deleting character select or making Jack one more roster slot beside the Knight.
