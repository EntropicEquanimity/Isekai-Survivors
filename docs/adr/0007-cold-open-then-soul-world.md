# Cold open, then Soul World; Rogue first

The isekai only lands if the first session is the abduction. We decided the first Run is a cold open on the Planet: no Soul World, no Vessel select, no Planet select, Rogue only, 0% Salvage. After that Run ends, Jack wakes in a tiny Soul World and the Heart / Wardrobe / Orrery / Reliquary loop begins. Knight and Samurai are early Skill Tree nodes; later Vessels are deeper nodes or Planet clears. Starting in the hub would make the monitor-flash a cutscene instead of the game.
